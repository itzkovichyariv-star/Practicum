# סביבת בדיקות

```bash
npm test               # 24 בדיקות לוגיקה (Node בלבד, מהיר)
npm run test:e2e       # 58 בדיקות בדפדפן אמיתי
npm run test:baseline  # השוואה מסך-מסך מול main
```

## בדיקת בסיס — מה השתנה ומה לא

`npm run test:baseline` מרנדר כל מסך פעמיים — פעם מ-`main` ופעם מהענף — עם
אותם נתונים בדיוק, ומשווה. הוא מדפיס לכל מסך «זהה לבסיס» או את ההבדל המלא,
כדי ששום שינוי לא יתחבא מאחורי תווית. הוא גם בודק שפתיחת האפליקציה בלבד
אינה נוגעת בנתונים השמורים.

## איך פותחים את סביבת הבדיקות ידנית

פתח את `index.html` עם `?test=1` בסוף הכתובת, למשל:

```
file:///.../index.html?test=1
```

בראש הדף תופיע רצועה כתומה־חומה. כל עוד היא שם, הדף מבודד.

## מה סביבת הבדיקות מבטיחה

| | |
|---|---|
| **נתונים** | כל מפתח אחסון מקבל קידומת `TEST__`. נתוני האמת לא נקראים ולא נכתבים. |
| **ענן** | הסנכרון מנוטרל בכוח. `supabaseSaveData()` מחזיר `false` מיד, גם אם הסנכרון מופעל בדפדפן. |
| **הודעות** | כל `mailto:` וכל קישור ל-Outlook נחסמים ונרשמים ב-`BLOCKED_SENDS`. שום הודעה לא יוצאת. |
| **סיסמה** | שער הסיסמה מדולג — אין כאן נתונים להגן עליהם. |

מצב הבדיקות נדלק אוטומטית בכל מקום שאינו הכתובת הרשמית (`yarivitzkovich.github.io`),
כולל פתיחה מקומית מהדיסק. אפשר לכפות אותו עם `?test=1` ולכבותו עם `?test=0`.

## ההבטחה שהבדיקות אוכפות

> על רשומת סטודנט שכבר קיימת, הקוד הזה כותב **אך ורק** `candidacy` ו-`candidateId`.
> לעולם לא סטטוס, לא קובץ, לא קישור.

הרשימה המלאה של השדות המוגנים נמצאת ב-`PROTECTED_STUDENT_FIELDS` בתוך `index.html`.
אחרי כל פעולה שמשנה נתונים, `runGuarded()` מריץ `verifyNoStudentStatusChange()`,
ואם התגלה שינוי אסור הפעולה **מבוטלת אוטומטית** והמצב חוזר לקדמותו.

## בדיקת קישורי קבצים

1. פתח עם `?test=1` → הגדרות → «בטיחות נתונים ושחזור» → **טען נתוני דוגמה**.
2. גלול ל-«🔗 קישורי קבצים». הטבלה מציגה כל קובץ בשלוש עמודות קישור:

| עמודה | מה היא פותחת |
|---|---|
| **תיקייה (היום)** | ההתנהגות הקיימת — התיקייה המשותפת, כלומר קורות החיים של כל הסטודנטים |
| **קובץ — מציג** | `onedrive.aspx?id=<קובץ>&parent=<תיקייה>` |
| **קובץ — נתיב ישיר** | נתיב מלא לקובץ |

3. לחץ «פתח» ובדוק איזה סגנון נפתח נכון מול SharePoint שלך.
4. סמן «הפעל קישור ברמת הקובץ» ובחר את הסגנון שעבד.

הקישורים נבנים משם הקובץ **השמור ברשומה**. אם קובץ שונה ידנית ב-OneDrive,
הכתובת לא תמצא אותו — לכן הטבלה מציגה את השם השמור בכל שורה.

**כבוי = בדיוק ההתנהגות הקיימת.** ההגדרה לא נוגעת בשום קובץ ולא משנה שמות,
ולכן קישורי שיתוף שכבר נשלחו לארגונים ממשיכים לעבוד בכל מצב.

## נקודות שחזור

נשמרת נקודת שחזור לפני כל פעולה שמשנה נתונים. בהגדרות → «בטיחות נתונים ושחזור»
אפשר לראות את עשר האחרונות, לשחזר לכל אחת מהן, או להוריד אותה כ-JSON.

## מבנה

- `run-tests.js` — שולף את הבלוק שבין `BEGIN CANDIDACY-CORE` ל-`END CANDIDACY-CORE`
  מתוך `index.html` ומריץ אותו תחת Node. מקור אמת יחיד: אם הקוד המשולח משתנה,
  הבדיקות רואות את זה.
- `smoke.js` — טוען את `index.html` בדפדפן אמיתי, מזריע נתונים, מפעיל את הממשק,
  ובודק גם שמצב הייצור לא נפגע.
